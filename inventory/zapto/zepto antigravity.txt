================================================================================
ZEPTO API SCRAPING FLOW - EXACT REQUEST MAPPING
================================================================================

STEP 1: Autocomplete (Pincode -> Place ID)
--------------------------------------------------------------------------------
* Endpoint: GET https://bff-gateway.zepto.com/api/v1/maps/place/autocomplete/?place_name={PINCODE}
* Example: ?place_name=400001
* Response Extraction: 
  place_id = response.json()["predictions"][0]["place_id"]

STEP 2: Place Details (Place ID -> Coordinates)
--------------------------------------------------------------------------------
* Endpoint: GET https://bff-gateway.zepto.com/api/v1/maps/place/details/?place_id={PLACE_ID}
* Response Extraction:
  lat = response.json()["result"]["geometry"]["location"]["lat"]
  lng = response.json()["result"]["geometry"]["location"]["lng"]

STEP 3: Serviceability & Store Mapping (Coordinates -> Store ID)
--------------------------------------------------------------------------------
* Endpoint: GET https://bff-gateway.zepto.com/api/v1/user/customer/address/location?latitude={LAT}&longitude={LNG}
* Response Extraction: 
  store_id = response.json()["storeDetailedInfo"]["storeId"]

STEP 4: Product Search (Store ID -> Inventory Data)
--------------------------------------------------------------------------------
* Endpoint: POST https://bff-gateway.zepto.com/user-search-service/api/v3/search
* Exact Payload (JSON):
  {
      "intentId": "15ee84ca-caf4-4cd7-8be7-fd09639a5946",
      "mode": "AUTOSUGGEST",
      "pageNumber": 0,
      "query": "red bull",
      "userSessionId": "{SESSION_ID}"
  }

* Exact Required Headers:
  - "store_id": "{STORE_ID_FROM_STEP_3}"
  - "tenant": "ZEPTO"
  - "device_id": "{DEVICE_ID}"
  - "session_id": "{SESSION_ID}"
  - "request-signature": "{DYNAMICALLY_GENERATED_HASH}"
  - "app_version": "16.31.2"
  - "content-type": "application/json"
  - "accept": "*/*"

* Data Parsing & Field Mapping:
  1. Iterate through `response.json()["layout"]`.
  2. Identify ad placements versus organic listings:
     - If `widget["data"]["resolver"]["type"] == "product_grid"` -> is_sponsored = False
     - If `widget["data"]["resolver"]["type"] == "ads_post_search"` -> is_sponsored = True
  3. Iterate through `widget["data"]["resolver"]["data"]["items"]`.
  4. Target only product entries where `item["type"] == "PRODUCT_ITEM"`.
  5. Extract core attributes:
     - brand = item["data"]["product"]["brand"]
     - name = item["data"]["product"]["name"]
     - product_id = item["data"]["product"]["id"]
     - variant_id = item["data"]["productVariant"]["id"]
     - pack_size = item["data"]["productVariant"]["formattedPacksize"]
     - available_qty = item["data"]["availableQuantity"]
     - out_of_stock = item["data"]["outOfStock"]
     - selling_price = item["data"]["sellingPrice"] / 100  (Stored in paise, divide by 100 for INR)
     - mrp = item["data"]["mrp"] / 100  (Stored in paise, divide by 100 for INR)
     - discount_percent = item["data"]["discountPercent"]
     - discount_amount = item["data"]["discountAmount"] / 100  (Divide by 100 for INR)
     - average_rating = item["data"]["productVariant"]["ratingSummary"]["averageRating"]
     - rating_count = item["data"]["productVariant"]["ratingSummary"]["totalRatings"]
     - country_of_origin = item["data"]["product"]["countryOfOrigin"]
     - weight_in_gms = item["data"]["productVariant"]["weightInGms"]

* Brand & Duplicate Filtering Logic:
  - Filter by brand substring: `target_brand.lower() in brand.lower()`
  - Deduplicate on `variant_id` across widgets using a tracking set `seen_variant_ids` so sponsored entries already captured are not duplicated.
